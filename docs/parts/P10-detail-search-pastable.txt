### FILE: README_P10.md
```text
P10 integration
===============
1. Add include/xe/detail.h, include/xe/search.h, src/screens/detail.c, and src/screens/search.c.
2. Merge CMakeLists_P10_integration.txt into the existing root CMakeLists.txt.
3. Initialize P1 platform, P3 renderer, P4 text, P5 jobs/images, P6 net, and P8 data before showing either screen.
4. Call xe_detail_open(&meta) after choosing a title. Each frame call xe_detail_frame(dt, area). Poll xe_detail_play(type, id, sizeof(id)); episode ids use :S<season>:E<episode>.
5. Call xe_search_frame(dt, area) while search is active; poll xe_search_opened(&meta) after each frame. The returned metadata's heap fields transfer to the caller; for a stack XeMeta, free fields individually or use a project-owned helper that doesn't free the struct.
6. Escape/F1 switch pages in the smoke host. Enter triggers Search; arrow keys navigate the UI. Physical keyboard text insertion needs a text-input event from P1 if available; the portable draft currently handles backspace/Enter and remote keyboard controls. Extend the event branch to append printable characters using the exact P1 text event contract.

Limitations to resolve during integration:
- This bundle uses the P9 reference P3/P4/P5/P7/P8 APIs repeated below; verify exact signatures against your actual files.
- Episode metadata has a local display structure but no public setter/loader yet; P8 currently returns episode arrays through xe_data_meta callbacks. Wire that callback into the detail page to populate episode cards.
- Trailer playback, persistent list/watch progress, and provider-specific resume timestamps require later player/profile integration.
- UI layout is optimized for 1920x1080 and 1280x720; density is currently 1.0 because the supplied APIs do not expose a guaranteed logical-DP transform contract.
- Image cache handles are held for displayed results; release them when replacing/clearing the result list in a production lifecycle.
```
